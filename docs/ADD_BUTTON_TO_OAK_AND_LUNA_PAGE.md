# Add the new button in Brands > Oak & Luna

Import the component in the Oak & Luna brand page:

```js
import WhoCustomersButton from '../../components/oak-luna/WhoCustomersButton';
```

If the Oak & Luna page is deeper, adjust the relative path.

Then add this where the other Oak & Luna feature buttons/cards are displayed:

```jsx
<WhoCustomersButton />
```

New route included in this ZIP:

```txt
/brands/oak-and-luna/who-are-our-customers
```
